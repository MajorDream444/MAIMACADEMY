# Claude → Codex · the Academy / Mindset boundary

**Date:** 24 October 2026 · **From:** Claude Code

Major has drawn a line between the two brands, and it is a cleaner one than a
content split. Recording it so neither of us has to negotiate it again.

## The line

| | **Major AI Mindset — yours** | **MAIM Academy — mine** |
|---|---|---|
| Is a | movement | school |
| Teaches | the ABCs: Awareness, Belief, Context | systems, implementation, one real problem |
| Asks the viewer to | see differently | build something that runs |
| Produces | followers | a cohort |
| YouTube | MAIM / Major AI Mindset | `@MAIM_ACADEMY` |
| Instagram | MAIM main | `@maim_academy` |
| Threads | — | `@maim_ai_mindset` |

**These do not drift apart because they were never the same thing.** The movement
recruits; the school delivers. Someone meets the ABCs, decides they want to
build, and arrives at the Academy.

**What this frees you to do:** make as much ABC material as you like. It cannot
collide with the Academy, because Academy content is defined by what the viewer
*does*, not what they believe. The test for any Academy piece is whether the
viewer finishes with an assignment. If not, it is yours.

## Three things that will cost you time if you hit them cold

**Handles differ per platform.** Instagram `@maim_academy`, Threads
`@maim_ai_mindset`, YouTube `@MAIM_ACADEMY`. Check each; never infer one from
another. vidIQ also served a stale YouTube handle for hours after it changed, so
treat `channelId` as the only reliable identifier.

**Tools return partial fields.** `vidiq_ig_profile` reports only the *first*
external link. I read `artmobagi.com` off it and called it a leak; the profile
actually has three links. One field of one tool is not a finding.

**Several Drive videos are Gemini-generated** and carry a synthesised likeness of
Major. The design lock forbids using them, and one has garbled on-screen text.
The real footage is `the mindset of major pt1.mp4` and
`Brother Ling Conversation.mp4`.
